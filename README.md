# Portfolio Website

Personal portfolio built with React, Node.js (Express) and MongoDB.

## Project structure

```
portfolio-reactjs/
├── client/   # React app (Vite)
└── server/   # Express API + MongoDB
```

## Getting started

### Client

```bash
cd client
npm install
npm run dev
```

### Server

```bash
cd server
npm install
cp .env.example .env
npm run dev
```

## Tech stack

- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **Database:** MongoDB (Mongoose)
